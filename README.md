# aspeed-go

Go HAL for ASPEED SoC coprocessors, targeting bare-metal [TamaGo](https://github.com/usbarmory/tamago) (`GOOS=tamago`) firmware.

```
https://github.com/kyanitecomputer/aspeed-go
```

## Design

- **Zero external dependencies** — `go.mod` has no `require` entries. The `reg` package uses only `unsafe` from the Go standard library.
- **TamaGo-compatible** — direct volatile MMIO via `unsafe.Pointer`. No syscalls, no OS, no allocator. Safe from interrupt context.
- **Generated PAC** — register structs in `pac/` are generated by `aspeed-data` via the chiptool Go backend. Never hand-edit `pac/`.

## Repository structure

```
aspeed-go/
├── reg/        volatile MMIO primitives (Read32/Write32/SetBits32/…)
├── pac/        GENERATED Go register structs (one file per peripheral block)
└── hal/
    ├── uart/   16550 UART driver (placeholder — Phase B)
    ├── gpio/   GPIO driver (placeholder — Phase B)
    └── timer/  Hardware timer driver (placeholder — Phase B)
```

## Using the reg package

```go
import "github.com/kyanitecomputer/aspeed-go/reg"

// Read the AST2600 SSP control register
v := reg.Read32(0x1E6E2A00)

// Unlock the SCU (same key for AST2600/AST2700)
reg.Write32(0x1E6E2000, 0x1688A8A8)

// Toggle GPIO pin (read-modify-write)
reg.SetBits32(0x1E780000, 1<<4)
reg.ClearBits32(0x1E780000, 1<<4)
```

## Dependency on aspeed-data

The `pac/` package is generated by [`aspeed-data`](https://github.com/kyanitecomputer/aspeed-data) using the chiptool Go backend. To regenerate:

```sh
# From aspeed-data repo root:
dagger call generate --chiptool ../chiptool export --path ./
# Then copy aspeed-go-pac/ output here into pac/
```

The chiptool Go backend generates structs with `Base uintptr` fields and `Read<Reg>()`/`Write<Reg>()` methods that delegate to this `reg` package. The import path is set to `github.com/kyanitecomputer/aspeed-go/reg`.
